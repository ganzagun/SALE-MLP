# 📘 SALE-MLP: Structure Aware Latent Embeddings for GNN to Graph-free MLP Distillation
This repository contains the supplementary materials and implementation details for the paper:

SALE-MLP: Structure Aware Latent Embeddings for GNN to Graph-free MLP Distillation
Harsh Pal, Sarthak Malik, Rajat Patel, Aakarsh Malhotra
Accepted at IJCAI 2024

SALE-MLP is a novel framework for graph-free and structure-aware distillation from Graph Neural Networks (GNNs) to Multi-Layer Perceptrons (MLPs). It leverages unsupervised structural losses to align MLP feature space with graph topology, enabling efficient and scalable inference without requiring access to the graph during deployment.
